## 欢迎来到「正圆工坊」(公共版) APP

> 一款随机抽选APP，专为地偶DD而生  

### 特点
- 使用微信[小程序多端框架](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/miniapp/intro/)开发构建
> 理论上可同步发行微信小程序、`Android`和`iOS`双端APP，因QQ小程序也兼容微信小程序代码，故也可发行QQ小程序。
- 首创“团体+成员”复合抽取，并支持指定单个团体抽取
- 编辑抽取名单自动缓存
- 支持深色模式

### 「正圆工坊」微信小程序
微信搜一搜「正圆工坊」即可体验（2025年1月1日后）
